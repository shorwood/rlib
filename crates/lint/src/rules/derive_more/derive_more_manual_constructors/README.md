# derive_more_manual_constructors

## What it does

Finds public constant `new` methods that only assign their parameters to every struct field.

## Why is this bad?

An authored constructor obscures that construction has no validation, normalization, defaults, or
other policy and duplicates the interface generated by `derive_more::Constructor`.

## Example

```rust,ignore
impl Point {
    pub const fn new(x: i32, y: i32) -> Self { Self { x, y } }
}
```

## Use instead

Declare the structural constructor on the type.

```rust,ignore
#[derive(derive_more::Constructor)]
struct Point { x: i32, y: i32 }
```
