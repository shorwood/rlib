# `rlib::strum_manual_enum_string_conversions`

## Summary

Finds exhaustive `&'static str` enum methods equivalent to the names generated by Strum's `AsRefStr`.

## At a glance

| Field | Value |
| --- | --- |
| Group | `rlib::strum` |
| Cargo feature | `strum` |
| Purpose | API design |
| Default level | `warn` |
| Fix | Manual |

## What it catches

Finds exhaustive `&'static str` enum methods equivalent to the names generated by Strum's `AsRefStr`.

## Why this matters

The match duplicates every variant spelling and can drift from parsing and advertised names.

## Examples

### Triggers the lint

```rust,ignore
impl Stage {
    fn as_str(&self) -> &'static str {
        match self { Self::Planned => "Planned", Self::Active => "Active" }
    }
}
```

### Use this instead

Derive `strum::AsRefStr`; review named-method callers before removing a public compatibility shim.

```rust,ignore
#[derive(strum::AsRefStr)]
enum Stage { Planned, Complete }
```

## What it skips

No additional exclusions are documented.

## When to turn it off

Turn this lint off when the reported API is deliberate and callers depend on it.
