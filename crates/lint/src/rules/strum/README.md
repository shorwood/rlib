# Strum lints

## Summary

Rules that replace repeated enum helpers with Strum derives while preserving names, values, and iteration behavior.

## How to enable

Enable the `strum` Cargo feature to register this family. Enable the whole family with `rlib::strum`.

## Lints

| Lint | Summary | Purpose | Fix |
| --- | --- | --- | --- |
| [`rlib::strum_conflicting_enum_serializations`](./strum_conflicting_enum_serializations/README.md) | Finds Strum enum spellings whose parser languages overlap or whose output alias is selected only by the longest-alias fallback. | Correctness | Manual |
| [`rlib::strum_declaration_order_domain_contracts`](./strum_declaration_order_domain_contracts/README.md) | Finds `EnumIter` or `VariantArray` declaration order used directly by workflow, migration, priority, protocol, menu, or presentation APIs. | Code clarity | Manual |
| [`rlib::strum_defaulted_payload_enum_construction`](./strum_defaulted_payload_enum_construction/README.md) | Finds `EnumIter`, `EnumString`, or `FromRepr` derives that construct data-bearing variants with default payload values. | API design | Manual |
| [`rlib::strum_divergent_discriminant_contracts`](./strum_divergent_discriminant_contracts/README.md) | Finds generated `EnumDiscriminants` types that also derive serialization and therefore become an independently observed schema. | Correctness | Manual |
| [`rlib::strum_divergent_variant_name_contracts`](./strum_divergent_variant_name_contracts/README.md) | Finds enums whose advertised `VariantNames` spelling differs from an alias accepted by `EnumString`. | Correctness | Manual |
| [`rlib::strum_documentation_used_as_enum_messages`](./strum_documentation_used_as_enum_messages/README.md) | Finds `EnumMessage::get_documentation()` values sent directly to user-facing rendering, response, error, or message APIs. | Style | Manual |
| [`rlib::strum_filtered_enum_count_contracts`](./strum_filtered_enum_count_contracts/README.md) | Finds `EnumCount::COUNT` used by APIs claiming an enabled, visible, supported, actionable, or available subset when the enum contains variants excluded from that domain. | Code clarity | Manual |
| [`rlib::strum_manual_discriminant_enums`](./strum_manual_discriminant_enums/README.md) | Finds private unit enums that mirror every variant of a payload enum through a one-to-one `From` conversion. | Code clarity | Manual |
| [`rlib::strum_manual_enum_accessors`](./strum_manual_enum_accessors/README.md) | Finds complete owned, shared, and mutable `Option` accessor families for every tuple variant when they exactly match Strum's `EnumTryAs` derive. | API design | Manual |
| [`rlib::strum_manual_enum_counts`](./strum_manual_enum_counts/README.md) | Finds inherent constants and zero-argument methods whose integer value exactly repeats an enum's active variant count when Strum's `EnumCount` derive is directly available. | API design | Manual |
| [`rlib::strum_manual_enum_iteration`](./strum_manual_enum_iteration/README.md) | Finds hand-written functions, methods, simple `IntoIterator` implementations, and iterator adapters that yield every unit enum variant exactly once in declaration order when Strum is a direct dependency. | API design | Manual |
| [`rlib::strum_manual_enum_metadata`](./strum_manual_enum_metadata/README.md) | Finds exhaustive variant metadata and redundant message wrappers reproducible by `EnumMessage` or `EnumProperty`. | API design | Manual |
| [`rlib::strum_manual_enum_predicates`](./strum_manual_enum_predicates/README.md) | Finds complete inherent `is_*` method families that identify one enum variant apiece exactly as Strum's `EnumIs` derive does. | API design | Manual |
| [`rlib::strum_manual_enum_string_conversions`](./strum_manual_enum_string_conversions/README.md) | Finds exhaustive enum spelling methods and redundant wrappers equivalent to Strum's `AsRefStr`. | API design | Manual |
| [`rlib::strum_manual_enum_string_parsers`](./strum_manual_enum_string_parsers/README.md) | Finds exhaustive unit-enum `FromStr` and inherent Option parsers reproducible by Strum's `EnumString` derive. | Code clarity | Manual |

| [`rlib::strum_manual_variant_arrays`](./strum_manual_variant_arrays/README.md) | Finds exhaustive declaration-order arrays and slices of unit enum variants when Strum's `VariantArray` derive is directly available and explicitly selected for ambiguous collections. | API design | Manual |
| [`rlib::strum_manual_variant_names`](./strum_manual_variant_names/README.md) | Finds static string tables that repeat every enum variant's standard Strum name in declaration order. | Style | Manual |
| [`rlib::strum_noncanonical_string_policies`](./strum_noncanonical_string_policies/README.md) | Finds Strum variant strings that can inherit a smaller type-level naming policy without changing generated behavior. | Style | Partial |
| [`rlib::strum_non_roundtripping_enum_strings`](./strum_non_roundtripping_enum_strings/README.md) | Finds unit variants whose Strum-generated output spelling is not parsed back into the same variant. | Correctness | Manual |
