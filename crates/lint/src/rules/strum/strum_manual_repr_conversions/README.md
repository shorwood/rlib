# `rlib::strum_manual_repr_conversions`

## Summary

Finds exhaustive inherent `from_repr` matches that convert an explicitly represented integer into unit enum variants with the exact `Option` behavior generated by Strum's `FromRepr` derive.

## At a glance

| Field | Value |
| --- | --- |
| Group | `rlib::strum` |
| Cargo feature | `strum` |
| Purpose | API design |
| Default level | `warn` |
| Fix | Manual |

## What it catches

Finds exhaustive inherent `from_repr` matches that convert an explicitly represented integer into
unit enum variants with the exact `Option` behavior generated by Strum's `FromRepr` derive.

## Why this matters

The match duplicates every discriminant and can silently become stale. `FromRepr` derives the
conversion from the enum's resolved discriminants.

## Examples

### Triggers the lint

```rust,ignore
impl Status {
    const fn from_repr(value: u8) -> Option<Self> {
        match value { 1 => Some(Self::Ready), 2 => Some(Self::Done), _ => None }
    }
}
```

### Use this instead

```rust,ignore
#[derive(strum::FromRepr)]
#[repr(u8)]
enum Status { Ready = 1, Done = 2 }
```
